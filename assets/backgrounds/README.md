# Fallback backgrounds

Drop a handful of nature photographs here (JPG or PNG, at least 1600px on the
short side).

They serve two purposes: a fallback when the stock photo API fails during a
one-off render, and a complete source for a library build if you set
`"provider": "local"` in the profile and would rather not use a stock API at
all. With a pre-rendered library, a stock API outage can never cost you a
post — only delay a rebuild.

Use photos you own or that are explicitly licensed for reuse — this repository
is public, so anything in here is published with it. Unsplash and Pexels
downloads are fine under their licences; stock sites that forbid
redistribution are not.
